### 🏆 Featured Projects

#### 1. 📊 [Superstore Sales Analytics & ML Dashboard](https://github.com/Amirhossein375/superstore-analytics-dashboard)
* **Description:** An end-to-end Business Intelligence & Machine Learning dashboard to clean retail data, identify logical business leakages, and predict sales.
* **Core Tech:** Python, Pandas, SQLite, Scikit-learn (Linear Regression, Random Forest), Pickle, Streamlit.
* **Key Achievements:**
  * Cleaned daily transactions and performed group imputation using Pandas.
  * Designed lag-features (`Sales_Lag_1`) and trained time-series aware models to improve predictions.
  * Built a master runner controller (`run_project.py`) using `subprocess` for pipeline automation.

#### 2. 🔍 [AI-Powered Job Market Tracker](https://github.com/Amirhossein375/job-market-tracker)
* **Description:** An intelligent job search and matching platform that scrapes live tech listings and recommends matches based on semantic profile analysis.
* **Core Tech:** Python, BeautifulSoup, Requests, tqdm, SentenceTransformers (`all-MiniLM-L6-v2`), PyTorch, Cosine Similarity, Streamlit.
* **Key Achievements:**
  * Built a multi-step crawler with rate-limiting and CLI progress bars to scrape detailed job postings.
  * Developed a semantic search engine using pre-trained HuggingFace Transformers and Cosine Similarity to calculate profile-to-job match percentages.
  * Embedded a live interactive search and detailed job description viewer in a Streamlit web app.
